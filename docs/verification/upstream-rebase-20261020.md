## 冲突与取舍

按实际暂停顺序，共六次：

1. **子代理菜单与新顶栏**：保留上游自定义排序、图标模式和手机折叠规则；本地菜单成为 `header:subagents` 项，可移除和重新添加。移除旧的独立子代理／导出插槽，客户端从源码重建。
2. **历史世界书过滤与分卷压缩**：保留上游旧卷原样携带、超预算只合并最旧几卷的机制；先过滤历史世界书快照，再计算保留轮数和分卷预算。
3. **正则过滤与历史工具回放**：保留上游历史玩家消息与正文共同回放、保留本轮来信和 Claude 思考签名修复；将本地过滤接入回放及压缩。正文正则仅作用于助手正文，不改写玩家原话；过滤后为空的正文不生成空工具调用。
4. **正文单局覆盖与上游合并开关**：全局使用上游统一开关；保留本地按对话覆盖，以及重生成新增的 `replacingDshTurns` 等状态字段。
5. **手机轻量聊天与新页面修补**：合并 HTTP 注册、页面补丁及样式的相邻插入，保留 `/mobile` 和角色卡状态栏；保留上游世界书面板与正文排版样式。
6. **历史单局覆盖与上游合并开关**：保留单局历史选项和分叉继承，去掉旧提交试图恢复的第二个全局开关；跟随全局时读取上游统一的 `storyToolCall` 默认值。

没有需要放弃某一项能力的功能取舍，未整文件覆盖上游新实现。生成的 `client.js` 通过构建更新。

## 上游新增能力

- **分卷记忆**：每次压缩写新卷，旧卷不反复压缩；超预算时只合并最早几卷成前情总览，较新卷保持原文。摘要更重视事件、条件、数值变化及原话，可按关键词或轮次回查原文。
- **世界书快捷面板与热更新**：顶栏直接切换世界书、开关条目；进行中的游戏默认自动采用库内修改，可在设置中关闭自动采用。
- **MVU 变量编辑器**：酒馆状态页查看与编辑当前楼层的变量，支持树形字段和 JSON 编辑，并保护其他变量和并发版本。
- **人物卡封面与导出**：卡片工作台支持封面工具及 PNG 导出；人物卡库统一为一个导出入口，按卡片内容选择相应格式。
- **正文排版**：外观设置可调字号、行距、字距。
- **HTML 渲染深度**：仅渲染最近若干轮的人物卡 HTML，减少长对话的界面负担。
- **自定义顶栏**：快捷入口排序、移除、纯图标；手机默认最多三个入口，多余项放入更多菜单。
- **重生成与按意见改写**：合并为一个操作，不填意见重新生成，填写意见则基于当前正文改写。
- **历史工具回放**：历史玩家消息和模型正文一起回放，全局正文及历史工具调用合并为一个开关。
- **切换与桌面入口**：酒馆／原版 DSH 切换入口调整，可手动添加酒馆桌面快捷方式；独立酒馆窗口可打开原版 DSH。
- **存档诊断与恢复**：升级失败时可导出去除正文的诊断文件，找回磁盘存在但未登记的存档，并修复多种旧档／压缩中断形状。
- **开发评测工具**：小说／EPUB 转聊天记录、直接导入、追加长历史、分卷压缩及记忆问答评测。

同时纳入 Claude 思考签名、重生成空白／跳号／隐藏错层、导入即压缩、默认端口占用、安卓布局及手机输入框等修复。以上基于 Git 提交与实现核对，不把本地 QQ 桥接和手机轻量页算作上游新功能。
